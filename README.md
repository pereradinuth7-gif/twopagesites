# twopagesites

**A better first impression.**

The official website of twopagesites, a Sri Lankan web design agency helping businesses establish a professional online presence.

🌐 **Live Website:** https://twopagesites.org

---

## About

twopagesites provides website design and development services for businesses looking to build or improve their online presence.

This repository contains the source code for the agency's official website.

## Features

- Responsive website design
- Service and pricing information
- Contact and project enquiry form
- WhatsApp enquiry integration
- Website package selection
- Basic SEO configuration
- Mobile-friendly navigation

## Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layouts and responsive design
- **JavaScript** – Interactions and form functionality
- **Cloudflare Workers** – Website hosting and deployment
- **GitHub** – Source code management and version control

## Local Development

To run the website locally:

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Access the website through your local browser.

## Deployment

The website is hosted using Cloudflare Workers.

GitHub is connected to the Cloudflare deployment workflow, allowing updates to be deployed when changes are pushed to the configured production branch.

## SEO

The website includes:

- Canonical URLs
- XML sitemap
- Robots.txt
- Google Search Console verification
